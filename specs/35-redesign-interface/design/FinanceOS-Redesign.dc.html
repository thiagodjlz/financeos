Notas de design

Referência de tokens para portar este redesign ao Angular (variáveis SCSS em styles.scss e nos componentes de feature).

Cores base

Fundo — oklch(97.3% 0.006 80)
Superfície — #FFFFFF
Sidebar — oklch(21% 0.02 260)
Acento (ações) — oklch(56% 0.16 262)

Cores semânticas

Receita — oklch(56% 0.13 155)
Despesa — oklch(58% 0.17 25)
Pendente — oklch(72% 0.14 80)
Saldo — oklch(58% 0.13 230)

Tipografia & espaçamento

Fonte: Inter (400/500/600/700/800)
Título de página: 26–30px / 800
Título de painel: 15.5–16px / 700
Corpo/tabela: 13.5–14px / 400–600
Raio de borda: 10px (inputs/botões), 14px (cards)
Sombra padrão: 0 8px 24px oklch(30% 0.02 80 / 6%)
Densidade de tabela: confortável — padding 14px 12px por célula

Componentes

Sidebar: trilho de ícones (76px), expande para 236px no hover, sobrepõe o conteúdo (não empurra)
Status pill: fundo tonal 10% + texto na cor semântica, radius 999px
Switch de permissão substitui os checkboxes da tela de Perfis
Gráfico de evolução: barras (receita/despesa) + linha de saldo em SVG real, dados por mês
